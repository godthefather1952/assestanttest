# Assestant Test

A lightweight practice webpage for testing the `/assestant` Claude skill in a browser.

It contains 10 mixed questions across:
- simple math
- logic
- workplace scenarios
- Python
- Bash
- JavaScript

Difficulty ranges from 1/10 to 10/10 and the whole set is designed to be completed in under 10 minutes.

## Run locally

Open `index.html` directly in a browser.

## Publish with GitHub Pages

In GitHub:
1. Open **Settings**
2. Go to **Pages**
3. Under **Build and deployment**, choose **Deploy from a branch**
4. Select **main** and **/(root)**
5. Save

GitHub will provide the public Pages URL.
